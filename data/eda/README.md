# EDA snapshot

В каталоге находится обезличенный агрегированный срез данных для домашней работы №2.
Он получен из внутренних сводных таблиц контура отбора и не содержит сырых сцен,
траекторий, идентификаторов сцен или поездок, внутренних путей, URL и учетных данных.

## Файлы

- `funnel.csv` — число строк, сцен и поездок на этапах обработки для девяти батчей;
- `distributions.csv` — агрегированные распределения trajectory clusters, semantic tags
  и приоритетных contexts до и после отбора;
- `feature_percentiles.csv` — перцентили числовых признаков для одного
  репрезентативного батча валидных сцен;
- `snapshot.json` — дата среза, покрытие и правила обезличивания.

Батчи обозначены как `B01`–`B09` в порядке обработки. Trajectory clusters обозначены
как `C00`–`C19`. Соответствие внутренним источникам намеренно не публикуется.

## Ограничения интерпретации

- Одна сцена может состоять из нескольких исходных строк, поэтому `raw_rows` нельзя
  интерпретировать как число сцен.
- Semantic tags являются multi-label: суммы по тегам превышают число сцен.
- Высокий acceptance rate показывает действие текущих правил балансировки, но не
  доказывает полезность сцен для итоговой модели.
- Перцентили признаков описывают один крупный батч и используются для проверки масштаба,
  диапазонов и выбросов, а не для оценки временного drift.
- В срезе отсутствуют фактический статус конвертации, стоимость подготовки сцены и
  per-scene feedback модели.

## Воспроизведение графиков

Из корня репозитория:

```bash
python scripts/build_eda_figures.py
```

Скрипт использует только стандартную библиотеку Python и записывает SVG в
`reports/figures`.
